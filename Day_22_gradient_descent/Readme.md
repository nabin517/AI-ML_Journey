
# Gradient Descent from Scratch

A simple implementation of **Gradient Descent** using Python and NumPy to understand how machine learning models optimize their parameters.

## What I Implemented
- Linear predictions using weight and bias
- Mean Squared Error (MSE)
- Gradient calculation
- Parameter updates
- Iterative optimization
- Loss visualization
- Learning rate experiments

## Learning Rate Experiment

| Learning Rate | Observation |
|---|---|
| 0.001 | Slow convergence |
| 0.01 | Faster convergence |
| 0.5 | Divergence |

## Tech Stack
- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Takeaway
Understood how Gradient Descent minimizes model error by updating parameters using calculated gradients, and how learning rate affects convergence.
