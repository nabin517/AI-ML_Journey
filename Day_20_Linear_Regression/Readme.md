##  Project Overview

This project implements **Simple Linear Regression** using Python and Scikit-learn.

The model uses **CGPA as the input feature** to predict a student's **placement package as the target variable**.

It demonstrates the basic Machine Learning workflow, including data exploration, visualization, model training, prediction, and evaluation.

##  Objectives

- Understand the fundamentals of Simple Linear Regression.
- Analyze the relationship between CGPA and placement package.
- Split the dataset into training and testing sets.
- Train a regression model using Scikit-learn.
- Predict placement packages using CGPA.
- Evaluate model performance using regression metrics.
- Visualize the fitted regression line.
